# CodSoft DevOps Internship

## About This Repository

This repository contains all four tasks completed as part of the CodSoft DevOps Internship Program.

The projects demonstrate practical knowledge of DevOps tools, containerization, version control, web server configuration, and CI/CD automation.

## Tasks Completed

### Task 1: Docker
- Created a Dockerfile.
- Containerized a simple HTML web application.
- Practiced Docker image building and container management.

### Task 2: Git & GitHub
- Created and managed Git repositories.
- Practiced commits, pushes, and branches.
- Learned merging and Pull Requests.
- Practiced resolving merge conflicts.

### Task 3: Nginx
- Configured an Nginx web server.
- Created a custom HTML website.
- Added a custom 404 error page.
- Practiced web server configuration.

### Task 4: GitHub Actions
- Created a CI/CD workflow using GitHub Actions.
- Configured push and pull request triggers.
- Integrated Docker Buildx.
- Added automated project validation.
- Configured Docker image building.
